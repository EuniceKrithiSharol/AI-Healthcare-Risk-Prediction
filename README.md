# 🏥 AI Healthcare Risk Prediction & Analytics

An educational Machine Learning project that analyzes synthetic health-related indicators and demonstrates multi-class risk prediction using predictive analytics.

> ⚠️ **Important:** This project is for educational and portfolio purposes only. It uses synthetic demonstration data and is not a medical diagnosis or clinical decision-making tool.

---

## 🚀 Project Overview

Artificial Intelligence and Machine Learning can be used to analyze complex datasets and identify patterns.

This project demonstrates how a Machine Learning classification model can analyze multiple health-related indicators and estimate demonstration risk categories.

The project focuses on:

- Machine Learning
- Predictive Analytics
- Healthcare Data Analysis
- Multi-Class Classification
- Interactive Data Visualization

---

## 🧠 Machine Learning Approach

The model analyzes multiple input features and classifies each record into one of three demonstration categories.

### Input Features

- Age
- BMI
- Blood Pressure
- Glucose
- Cholesterol
- Physical Activity
- Smoking Indicator
- Family History Indicator

### Output Categories

```text
Low Risk
Moderate Risk
High Risk
```

---

## 🤖 Model Used

### Random Forest Classifier

Random Forest is used for multi-class classification and feature importance analysis.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/AI-Healthcare-Risk-Prediction.git
```

Move into the project directory:

```bash
cd AI-Healthcare-Risk-Prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
